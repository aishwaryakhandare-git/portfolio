SmartMark

SmartMark is a full-stack face recognition-based attendance system designed to automate and improve traditional attendance processes. It uses real-time facial detection to accurately mark attendance, reducing manual errors and preventing proxy attendance. The system includes role-based modules for Admin, Teacher, and Student. Admins manage users and classes, teachers conduct sessions, and students mark attendance using live face verification. Firebase integration ensures real-time data storage and synchronization.

AirCare AI 🌿

AirCare AI is a modern full-stack air quality monitoring platform designed to provide real-time AQI insights, environmental analytics, and personalized health recommendations through an interactive dashboard experience. Users can search any city to instantly fetch live air quality data along with environmental parameters including temperature, humidity, UV index, pollutant concentration, and overall AQI status. The platform simplifies environmental monitoring through visual analytics and helps users understand pollutants such as PM2.5, PM10, CO, NO₂, SO₂, and O₃ with health-focused recommendations.
